## Open Source Contributions

### 01 / PhotoCraft

**Rust-powered image editing.**

[![Merged](https://img.shields.io/badge/PR%20%23873-MERGED-238636?style=flat-square&logo=github)](https://github.com/storytold/photocraft/pull/873)

**[Curves: Black, Gray & White Point Eyedroppers](https://github.com/storytold/photocraft/pull/873)**

Contributed black, gray, and white point eyedroppers to PhotoCraft's Curves adjustment workflow.

- Black and white point sampling.
- Gray-point color neutralization with approximate luminance preservation.
- Regression tests covering multiple image depths and edge cases.
- Integrated into the project's main branch.

**[View merged contribution →](https://github.com/storytold/photocraft/pull/873)**
